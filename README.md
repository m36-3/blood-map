# BloodMap Iraq — Prototype v3

نسخة Front-end تجريبية تفاعلية لمنصة تنسيق خدمات الدم.

## حسابات التجربة
- مواطن / متبرع: `citizen` / `123456`
- كادر صحي: `staff` / `123456`
- مصرف دم: `bank` / `123456`

## سيناريو التجربة المقترح
1. ادخل بحساب `citizen`.
2. افتح «طلب دم» وأنشئ طلبًا جديدًا.
3. سجل الخروج ثم ادخل بحساب `bank`.
4. افتح «طلبات الدم» وستجد الطلب الجديد.
5. افتحه ثم جرّب «تأكيد التوفير» عندما يكون المخزون كافيًا، أو «نحتاج متبرعين» عندما يكون غير كافٍ.
6. سجل الخروج وادخل بحساب `citizen` لترى تغيّر الحالة والإشعارات.
7. جرّب صفحة «التبرع» لمحاكاة استجابة المتبرع للنداء.

## ما الذي تتضمنه v3؟
- 3 حسابات بصلاحيات متفاوتة.
- صفحة رئيسية خدمية بدل الخريطة.
- بحث فصيلة + مكوّن + محافظة.
- تفاصيل تفاعلية لمصارف الدم.
- إنشاء طلب دم ورفع مرفق تجريبي.
- Timeline للطلب.
- مراجعة المصرف.
- تأكيد توفير وخصم المخزون.
- إطلاق حملة متبرعين عند نقص المخزون.
- محاكاة استجابة المتبرع.
- إدارة مخزون الفصائل.
- إشعارات وحساب وتسجيل خروج.
- البيانات التشغيلية تبقى في الذاكرة أثناء تجربة الحسابات داخل نفس فتح الصفحة، لذلك يمكن الانتقال من المواطن إلى المصرف لمشاهدة نفس الطلب.

## ملاحظات
هذه نسخة UI/JavaScript محلية فقط. لا يوجد Backend حقيقي ولا قاعدة بيانات ولا تكامل مع وزارة الصحة أو مصارف الدم. جميع الأسماء والمخزونات والطلبات والمتبرعين افتراضية.
